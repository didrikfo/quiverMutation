# Review of <submission path>

referee: <persona id> · round: <NNN>
verdict: <accept | minor revision | major revision | reject>

## Reproduction

What was re-run, how long it took, whether the output matched. If nothing
was re-run, why not, and what smaller case was run instead.

## True?

Errors, gaps, unchecked cases. A counterexample if there is one, with the
command that produces it.

## New?

What `research/` already has on this, by identifier. "Nothing found for
<terms grepped>" is an answer.

## Evidenced?

Whether the evidence is stated specifically enough to be believed without
re-running it; what is missing.

## Scope

Does the title and claim match what was checked (n, classes, caps)? If the
claim reaches past the sample, give the narrowed wording.

## Required for acceptance

A numbered list the author can answer point by point. Empty if accept. The
author answers it in the same round (ROUND.md step 3.5), so make each item
doable in one sitting under the command limit, and mark any item that is
not (`[next round]`). Use **minor revision** only when every item is small;
use **major revision** when the claim stands or falls on an item.
