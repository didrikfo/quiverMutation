# "Reject => W" is not a consequence of step 7 and is false in general: J != 0 is exactly a circuit in a small graph, W is its length-2 ground-path case, and the "cancels" branch is a real reject

author: scholar · round: 027 · kind: proof (partial) + negative · thread: T5 · bears on: E-099, E-105, E-107, E-109, E-110

## Claim

1. **Step 7 does not enter.** J_i = ker(g_i : e_iAe_v -> (+)_b e_iAe_{t b}, p |-> (pb)_b) is defined by the parent A alone. Step 7 (and E-068/E-099) only converts "Cartan fails" into "J != 0"; it never exhibits an element of J. So "reject => W" is a statement about A, and no step of `mutateAtVertex` proves or fails it. The link E-099 needs ("step 7 returns the whole ideal") is not stressed by W-type kernels but is stressed by the ones below: on all four hand cases the real rewrite (`mutateAtVertex(..., checkCartan=True)`) fails the Cartan test exactly when J != 0.
2. **Lemma (proved, for algebras whose relations are monomials and two-term p - lam q).** Then A has a basis of nonzero path classes (up to scalar) and, for gate-admitted v (no class with p b = 0 for every out-arrow b), J_i != 0 iff the graph Gamma_i has a circuit. Gamma_i: vertices = nonzero classes of e_iAe_{t b}, one copy per out-arrow b; one edge per nonzero class gamma of e_iAe_v joining [gamma b1] and [gamma b2] (a zero product is a pendant edge to a "ground" vertex g, not a basis vector). x = sum c_gamma gamma lies in J iff c sums to 0 at every non-ground vertex. Gamma_i is bipartite (T_1 vs T_2), so negating T_2 rows turns this into a signed incidence matrix: J_i = flows conserved at all non-ground vertices = cycles plus ground-to-ground paths (circuits), dim J_i = E - V + (components without ground). The coefficients on a circuit are +-1 (up to the relation scalars), so every minimal element of J is an alternating sum along a circuit.
3. **W is the length-2 ground-path case; the other length-2 circuit is the "cancels" branch.** Out-degree 1: every edge is pendant, every circuit is a ground path, and the shortest has two edges, i.e. two classes with p1 b = p2 b != 0 in A. So for out-degree 1, J != 0 => (p1 b = p2 b, p1 != p2) is proved (not a statement about generators: p1 b - p2 b may be a combination of several relations, see G). Out-degree 2: circuits of length 2 are (nz/zn) two classes with the same b1-product and both b2-products 0 = W exactly, and (nn) two classes with equal nonzero b1- AND b2-products = a 2-cycle: p1 b1 = p2 b1 and p1 b2 = p2 b2, x = p1 - p2 in J but p1 b2 != 0. **W fails there.** Circuits of length >= 3 (ground paths through 3 classes, cycles of length >= 4) are further kernels with no two-term witness.
4. **Hand cases (all gate-admitted, no single path in J, rewrite Cartan FAILS):** D (nn): square 1-2-4, 1-3-4 with `1245=1345` and `1246=1346`, v=4, out 5, 6 (this is E-105's 19 two-out hand-built rejects). G (out-degree 1): `1245=175`, `1345=175`: p1 b - p2 b is a combination of two relations, hasLongSquare False, J != 0. H (length-3 ground path, no equal-signature pair): arrows 1->2,3,7 ->4 -> 5,6 with `1245=1345`, `1346=1746`, `1246=0`, `1745=0`; x = 124 - 134 + 174.
5. **On the walks the data are exactly W.** Over gate-admitted steps of three capped walks, "J != 0" coincides with "exists two path combinations (scalar-normalised) with equal signature (p b)_b" (W2, a superset of W) in every row; kinds found: nz/zn at out-degree 2, n at out-degree 1, never nn, never a longer circuit. So within reach, J is always a length-2 ground path; why nn and longer circuits do not occur on LNA-derived algebras is **open**.

What is not claimed: relations with >= 3 terms (E-105 samples no length-2 sums; walks may contain "sum" relations, not tallied here), out-degree >= 3, parallel arrows (skipped by `relationsFrom` lift: none of my rows had arrowRels beyond the lift, but I did not count). The lemma's scalar case (p = lam q) is argued, not tested with lam != 1 beyond the walks' sum-type relations.

## Evidence

Proof of the lemma, step by step. (a) Basis: the ideal generated by monomials and p - lam q is spanned by monomial-containing paths and differences of congruent paths, so classes of paths under the generated congruence, those containing a path in the monomial ideal being 0, form a basis of A. (b) For x = sum c_gamma gamma, x b = sum c_gamma [gamma b], and [gamma b] is a basis vector or 0, so x b = 0 iff c sums to zero over each fibre of gamma |-> [gamma b], b = b1, b2. (c) That is the vertex conservation described above. Least sure step: (a) when scalars lam != 1 occur and a cycle of relations forces p = lam p (then p = 0 and the class is zero: handled, but I did not code it).
