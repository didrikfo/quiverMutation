## Claim

## Evidence

**Primary certificate (any-slot; referee's route, AI Prop 2.36 + Thm 2.35, no Thm 2.44).** (F) holds (below). Suppose T > T' and T' is not an irreducible left mutation of T. By Prop 2.36 some irreducible left mutation L = mu^+_X(T), at *any* summand X, has T > L >= T', L != T'. L is silting (Thm 2.31), so presilting and K_0-unimodular (Thm 2.27), and L = (T \ X) + Y with Y indecomposable (Cor 2.28, Prop 2.33). So: **no slot X and no listed indecomposable Z with (T \ X) + Z presilting, unimodular, T >= (T \ X) + Z >= T', (T \ X) + Z != T, T' implies T' = mu^+(T)** (T' is a mutation at the exchanged summand, since it differs from T in one summand). Dually for T' > T. This needs no functorial finiteness and no silting reduction; it still needs the object list to be complete (item 1 of the response). It is `irred_any` in `scholar_irred.py`; it runs with no `selfok` filter.

**Fixed-slot certificate (the original argument, kept as a parallel check).** T = D^b(B_n) = K^b(proj B_n) (gldim finite) is Krull-Schmidt, k-linear Hom-finite with a silting object, so condition (F) holds (AI text after the definition of (F), before Thm 2.35).
