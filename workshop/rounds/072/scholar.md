**Most promising question (next few rounds):** Does the J = 0 join test ever return NO across a step with J != 0, on a certified inequivalent pair?

Why: the "25 of 25 joined" result and the T10 agenda item both rest on J = 0, and the theorems we have do not give it. Oppermann Thm 1.1 needs only "no degree-0 loop at i" and gives End(T) = H_0(kM) with J in H_1 (E-189). End(T) and Hom(T,T[-1]) cannot see J (E-181, E-184). So until a test can say NO on a known-inequivalent J != 0 pair, the premise is a hypothesis, not a check. The n = 7 control is the cheapest way to get that power.
