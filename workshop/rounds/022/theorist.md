# The cord criterion is a depth-1 rule plus a peeling depth 1 + min(a,b); "within 3 steps" is true only for n <= 9 (n = 10 needs 4, n = 12 needs 5)

author: theorist · round: 022 · kind: result (mechanism + refutation of the depth clause)
thread: T6 · bears on: E-101, E-094, E-089, H-017

## Claim

**Meaning of "cord".** In E-089/E-094/E-101 and the scripts (`maverick_predict.py`, `toolsmith_cords.py`) a "cord member" is a reached
algebra with *arrows >= n and no parallel arrows*, i.e. the (connected) quiver has an undirected cycle. It is NOT the quipu cord of
GLOSSARY.md (a path hanging off the main string; quipus have n-1 arrows). The reached cycles all carry a sum (commutativity) relation
(E-094: 2376 of 2376), so "cord = commutativity cycle" is the right reading; the name is a historical misnomer, and I suggest "cycle member".

**(1) Depth 1.** Write a relation of m >= 3 arrows as the zero path x0 -> x1 -> ... -> xm. Call it *blocked* if a relation ENDS at x1
(= x0+1) AND a relation STARTS at x_{m-1}. Claim D1: an LNA has a cycle member at mutation depth 1 iff some relation of >= 3 arrows is
not blocked. Tested exhaustively, 0 mismatches: n = 6 (42 LNAs), 7 (132), 8 (429), 9 (1430), 10 (4862).

**(2) Peeling.** If the LNA has exactly one relation of >= 3 arrows (the others have 2), its minimum cycle depth is 1 + min(a, b), where
a = number of consecutive 2-arrow relations starting at x0-1, x0-2, ... and b = number of consecutive 2-arrow relations starting at
x_m-1, x_m, ... . Tested: 195 of 195 LNAs at n = 8, 9, 10 with depth >= 2 (of 195 + 39 two-big-relation LNAs: 18 at n = 8, 56 at n = 9, 160 at n = 10; table
`theorist_blocked_depths.txt`), plus predicted-then-confirmed: `222302222` n = 11 depth 4 (a = 3, b = 4), `2222302222` n = 12 depth 5 (a = b = 4).
Consequence: with a + 1 + 1 + b <= n - 2 digits (m = 3) the maximum depth over all LNAs is 1 + floor((n-4)/2): 3 for n = 8, 9; 4 for n = 10, 11;
5 for n = 12. Observed maxima: n = 8: 3 (LNA 205), n = 9: 3 (5 LNAs), n = 10: 4 (one LNA, `22230222`, index 2083), n = 12: 5 (one run).

**(3) Refutation.** E-101's clause "within 3 mutation steps" is a fact about n <= 9, not about the criterion. At n = 10, `22230222` has a
relation of 3 arrows and no cycle member at depth <= 3 (first at 4). The "iff relation >= 3 arrows" part survives: n = 9, L = 4: all 1430
LNAs checked at L = 1 against rule D1, the 56 blocked ones to L = 4 (all found, depth <= 3); all 128 {0,2}-LNAs: 0 cycle members to depth 4.
n = 10: the 160 blocked ones all have a cycle member by depth 4 (depth table below). Not claimed: a proof of any of this, or of "no cycle ever" for
digits in {0,2} (depth <= 4 at n = 9, <= 5 at n = 8 by E-101, nothing deeper).

## Evidence

Mechanism for the unblocked case (a derivation, step marked): mutate at x0 (or, mirrored, at x_m). Right A-modules, P_i = paths starting at i.
The approximation of P_{x0} by add(A/P_{x0}) is P_{x1} -> P_{x0}, with cokernel S_{x0} and kernel K generated by the path x1..x_m, i.e. a
quotient of P_{x_m}. So the new vertex x0' gets an arrow x1 -> x0' (reversal of x0 -> x1) and a NEW arrow x0' -> x_m (from K), and the
composition x1 -> x0' -> x_m equals the path x1 -> ... -> x_m (generator of K): the commutativity relation. In the data (n = 4, `30`, depth 1):
arrows 2->1, 1->4, 2->3, 3->4 with relation (2,1,4) = (2,3,4). The cycle has m+... arrows: x1, x0', x_m and the path x2..x_{m-1}.
**Why 3:** for m = 2 the second path x1 -> x2 is a single arrow, and the new composite x1 -> x0' -> x2 equals it, so that arrow is absorbed:
the arrow count stays n-1 and the quiver stays a tree (verified: only trees reached from {0,2} LNAs, census below). For m >= 3 the second
path has length m-1 >= 2, no arrow can be absorbed, and the count is n. So "3 arrows" = "the parallel path has length >= 2".
Weakest step: that the quiver of End(T') is read off as stated (I checked it against the tool's output for depth-1 members at n = 4, 5, 7,
not proved), and why a relation ENDING at x1 (resp. STARTING at x_{m-1}) blocks the move (the observed rule, no derivation).
Why depth is 1 + min(a,b): a blocked end is a chain of 2-relations; each mutation at the end of a 2-relation shortens the chain on that side by
one (the 2-relation is absorbed as above), so the cycle appears after min(a,b) peeling steps plus the final one. Fits 195 of 195; the
chain-shortening step itself I did not check by hand. With several relations of >= 3 arrows the plain formula fails (31 mismatches at
n = 8..10, all with two big relations in contact, e.g. `2230302` depth 2, formula 1): the chains may pass through a 3-relation; no formula offered.
Closure for the negatives: from the 2^{n-2} {0,2}-LNAs every labelled algebra reached (both directions) is a tree with only monomial
2-arrow relations: 825 algebras at n = 5 (depth 5), 1481 at n = 6 (depth 4), none with a sum or longer relation. This is the content of
"rad^2 = 0 never cycles" and is a census, not a lemma. Note the derived class does contain cyclic algebras without sum relations (the
3-cycle with two zero relations is tilted of type A_3) that the tool never reaches from n = 3, `2` (depth 9): the criterion is about the
repo's mutation, not about the derived class.

Depth table (blocked LNAs by n and depth; all with a relation >= 3): n = 8: depth 2: 17, 3: 1; n = 9: depth 2: 51, 3: 5; n = 10: depth 2: 142, 3: 17, 4: 1.
