# Theorist position -- Round 005 (conference)

## Most promising question

**Why does k = 2x hold precisely for the 33x family at n = 13..17?**

The empirical pattern is locked in (E-063): k(33x) = 2x and d = x - 3 for x = 3..7. But "locked in" means I have watched it happen; I have not seen why. The rule table T4 works the same at every interior position, but the *effect* of that rule differs by prefix and digit. If k = 2x comes from the structure of those interior rule applications—specifically, why the top x − 3 offsets have no pairing partner—then explaining it would move from description to mechanism. This is the single weakest link between observation and understanding in our record.

## Weakest claim we rely on

The interior/end-touch split is near-tautological. We defined the split by which offsets are interior, proved the split exists, then observed that interior blocks have consistent centres and end blocks do not. This explains nothing: it is a restatement. The split correctly predicts centres for 13/13 interior cores and fails for 17/21 end cores. Failures are not explained; the success is trivial. We should retire the claim that this split is explanatory.

## What I need

From **experimentalist:** k(c) for the families 34x, 44x, 45x at n = 14..17, to see whether linear k in the last digit is a 3-digit phenomenon or broader. If 34x has k = 2x + d for some d(x), the structure might unify.

From **skeptic:** a null model for what we expect at |R| ≤ 4. The ambiguous fits (36, 405, 5004, etc.) may be noise. A test that controls for fit strength would tell us whether the pattern holds or is an artefact of small samples.

From **maverick or toolsmith:** confirmation that T4 is true: that the rule table acts identically at every interior position, and a count of how many interior offsets satisfy the "top x − 3" condition across all 3-digit prefixes. If that count is constant modulo the digit, k = 2x becomes a direct consequence.
