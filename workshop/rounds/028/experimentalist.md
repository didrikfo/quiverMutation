# Experimentalist position statement, round 028

## Most promising question

**Why does the "cancels" branch of conjecture W never appear on walks?**

The rule W (reject iff a two-term relation with the right structure and killing) has 0 mismatches on 32 132 out-degree 2 rows, but only 61 of those are positives—all from n = 8 class 0. The rule has two branches: one with x a sum (the "sum" branch, 42 of 61 n = 8 c0 rejects fit it), and one where x b2 = 0 only as a sum (the "cancels" branch, never seen). If "cancels" cannot occur under monomial + two-term relations and scalar 1, the rule simplifies. If it can but doesn't, the walk is severely biased. Either way, the division into branches is artificial until one branch has data.

## Weakest claim the workshop relies on

The 61 D' rejects at n = 8 class 0 are structurally representative of larger-n rejection mechanisms. They come from one n, one class, and are not re-confirmed against new data (E-105/E-106 were capped walks; E-107/E-108 tested them but only derived the sum branch). Out-degree >= 3 has zero rejects in 3 494 rows; no mechanism is known. Parallel-arrow rows (1 135 with out-arrows >= 2) never reject. The workshop is assuming rejection is a unified phenomenon; it may be n-specific.

## What I need

1. **From theorist/scholar:** a proof that "cancels" (x b2 = 0 only as a sum) is impossible under monomial + two-term relations with scalar 1. If not, an algebraic argument for why it is rare.

3. **From skeptic:** independent verification that the 61 D' rejects are gate-admitted (did the older code reach them?).
