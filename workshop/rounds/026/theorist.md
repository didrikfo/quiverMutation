# On every out-degree 2 row of the n = 8 class 0/1 and n = 7 class 0 walks, the step rejects iff a two-term commutativity relation runs through v into one out-arrow and each of its two prefixes is zero when continued by the other out-arrow

author: theorist · round: 026 · kind: conjecture
thread: T5 · bears on: E-099, E-105, E-107, E-108

## Claim

Setting: an algebra A on the BFS walk with a mutable vertex v of out-degree 2, out-arrows b1, b2, no parallel arrows (so `relationsFrom` lifts), and J = {x in e_i A e_v : x*b1 = x*b2 = 0}; "reject" = J != 0 (kerdim > 0, the Cartan congruence fails, E-099).

**Conjecture W.** J != 0 iff there is a relation R = p1*b1 - p2*b1 (two terms, every term ends `... v b1`, p1 != p2 paths i -> v) such that x = p1 - p2 is nonzero in A and p1*b2 = 0 = p2*b2 in A (b1, b2 in either order). Then x*b1 = 0 = x*b2, so x in J, and x is the explicit kernel element the round-025 proceedings asked for. "Both out-arrows carry a relation ending through v" is what W implies on the b2 side (the zero relations) but is not the condition: it is only the shape of W.

What distinguishes the 42 from the 754: in the rejecting rows one arrow carries a commutativity relation with BOTH sides through v (a long-sided square on that arrow), and the other arrow kills both sides. In the accepting same-shape rows the commutativity relation either has only one side through v (e.g. `4-2-3-7 = 4-5-7`, v = 3) or the side paths are not killed by the other arrow. Not claimed: the converse direction J != 0 => W is only tested, not proved; rows with parallel arrows are not covered; no claim for out-degree >= 3 or out-degree 1 (there E-102/E-105's long square is the same W with b2 absent).

## Evidence

|---|---|---|---|---|---|---|---|
| n=8 class 0 | 4 924 | 5 864 | 789 | 55 | 0 | 0 | 5 020 |
| n=8 class 1 | 5 607 | 6 746 | 357 | 15 | 0 | 0 | 6 374 |
| n=7 class 0 | 5 556 | 5 192 | 267 | 0 | 0 | 0 | 4 925 |

Shape of the witness in every rejecting row (70 = 55 + 15): R has 2 terms; min term length 3 in 68, 4 in 2 (n=8 c0); each term of x times b2 is zero individually ("termwise-zero" 70/70; none cancels against the other). Both-carry rows (the control): 1 361 in n=8 c0 with 55 rejects (all inside the both-carry set), 971 in class 1 with 15, 896 at n=7 with 0. Inside both-carry rows the signature "one arrow carries {M, S2}, the other only {S2}" holds for all 55 rejects (48 + 5 + 2) but also for 114 accepting rows, so shape alone does not separate; W does (0 mismatches over 17 802 rows, including every accepting row).

Hand check (first reject, v = 3, out 6, 8): `5-1-3-6 = 5-7-3-6` gives x = 5-1-3 - 5-7-3; x*8: `1-3-8 = 0`, and `5-7-3-8 = 5-7-3-6-8 = 0` using `7-3-6-8 = 7-3-8` and `5-7-3-6-8 = 0`. So x in J. This is the derivation step: the zero on the p2 side is not a relation ending at b2 but follows from one further commutation.

Derivation from step 7 (E-099: (i,k) entry = dim ker psi_i, rewrite fails iff some ker g_i != 0): W exhibits an element of ker g_i = J directly, so W => reject follows from E-099 with no new step. The converse needs: J is generated by relation-derived elements (R/b1 for R through v). Least sure step; held empirically only.
