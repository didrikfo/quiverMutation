## Claim

Let A = kQ/I with Q finite and acyclic, v any vertex, D = sum_{j != v} P_j, f = (b)_b : P_v -> sum_{b: v -> t} P_t the out-arrows
of v, Y = [P_v --f--> sum_b P_t] (two-term, as in E-128 and round 129), T = Y + D. Write A(x, y) for paths x ~> y mod I, phi_i : A(i, v) -> sum_b A(i, t(b)), p |-> (pb)_b, and J_i = ker phi_i.
(a) Hom(T,T[m]) = 0 for m >= 1, and Hom(T,T[-1]) = sum_{i != v} J_i; T generates K^b(proj A). Hence **T is tilting iff every
phi_i (i != v) is injective**, at every vertex, gate-admitted or not, with or without an out-arrow.
(b) `mutation.isTiltingAtVertex(A, v)` returns exactly "every phi_i is injective" on acyclic Q, **provided every relation passed has
one source and one target** (`arrowPaths.isIllegalRelation` False). Without it (b) is false: abd + cd on 1->2->3->5, 4->3 at v = 3.
(c) If v has an arrow out and every phi_i is injective, then `isMutable` admits v. So on acyclic quivers
"gate and isTiltingAtVertex" = "v has an out-arrow and isTiltingAtVertex"; the gate adds nothing to the injectivity test.
Hence E-327's 298 337 of 298 337 agreement is a theorem, not a sample law, and H-030's 8 over-admissions are by (a) and E-128 L1
exactly the cases "J_i != 0 with no path in J_i" (E-080 shape on 7, E-112's circuit on 3277, per E-327), not a presentation dependence.
Not claimed: anything on cyclic quivers (there Hom(Y,Y[-1]) can be nonzero, E-130 (M3), and the function enumerates simple paths only);
that the library's child equals End(T) (H-023). Refuted by: one acyclic (algebra, vertex) where H[1] != 0, H[-1] != sum J_i, or
`isTiltingAtVertex` differs from Hom.

## Evidence

**Proof of (a).** Convention (as round 129's engine): Hom(P_x, P_y) = A(x, y) = paths x ~> y mod I, composition = concatenation (the library's p then b = pb).
Y has P_v in degree -1 and sum_b P_t in degree 0.
- *Approximation.* Every element of Hom(P_v, P_j), j != v, is a combination of paths v ~> j of length >= 1, each of the form b q
  with b an out-arrow of v; so every map P_v -> P_j factors through f. (No minimality, no I in R^2 needed.)
- Hom(T,T[m]) = 0 for |m| >= 2: the complexes live in degrees -1, 0. Hom(D,D[m]) = 0 for m != 0.
- m = 1: Hom(D, Y[1]) = 0 by degrees. Hom(Y, P_i[1]): a chain map is g : P_v -> P_i (no conditions), null-homotopic iff g = s f;
  it is, by the approximation. Hom(Y, Y[1]): a chain map is h : P_v -> sum P_t (the only overlapping degree, no conditions),
  null-homotopic iff h = s0 f + f s1; take s1 = 0 and s0 from the approximation (each P_t is a summand of D: t != v, no loops).
- m = -1: Hom(Y, D[-1]) = 0 by degrees. Hom(P_i, Y[-1]): a chain map is g : P_i -> P_v with f g = 0, no homotopies; g is a
  combination p of paths i ~> v, and f g = 0 says p b = 0 for every b: this is J_i. Hom(Y, Y[-1]): one component
  h : sum P_t -> P_v, h_b in paths t(b) ~> v, which is 0 because b then such a path is an oriented cycle.   **<- the only use of acyclicity**
- Generation: P_v is in thick(Y, sum P_t), so thick(T) contains every P_j.
So T is tilting iff sum_{i != v} dim J_i = 0. This is E-124 + E-128 (L2) + E-130 without the citation of AI 2.31 (E-130 needs it for
silting on cyclic quivers; on acyclic ones Hom(T,T[1]) = 0 is the two lines above). If v has no arrow out, Y = P_v[1] and
the same lines give J_i = A(i, v): tilting iff no nonzero path enters v.

**Proof of (b).** For i != v the function takes all paths i ~> v (`allPathsBetween`: vertex-simple, which on an acyclic quiver is all
paths, one per choice of parallel arrow). `idealSpanningSet` gives all u r w, which spans I(i, v) when the relations are uniform;
`_rowReduce` returns independent rows with distinct heads, each head the smallest key of its row, so quotientDim = dim A(i, v).
`reduceAgainstPivots` is linear and its result is the unique element of x + span(pivots) with no pivot key (if two differ, the
difference is sum c_k r_k with no pivot key; the smallest pivot with c_k != 0 occurs only in its own row, so c_k = 0). So it is
a linear map with kernel exactly I(i, t), an injective coordinate map of A(i, t). The row of path p is therefore the coordinate
vector of phi_i(p); paths span A(i, v), so the rank of the rows is dim im phi_i <= quotientDim, with equality iff phi_i is injective;
the function returns False at the first i with rank < quotientDim. **Weakest step:** this is a reading of the code, not a proof
about it; it assumes relations are uniform (one source, one target per relation). Nothing enforces this (`relationsFrom`, `isTiltingAtVertex`
and `arrowPaths.source/target` read the first path only), and the referee's abd + cd shows the reading fails without it; hence the precondition in (b).

**Proof of (c).** The gate refuses v (v has an out-arrow, no loop on acyclic Q) only when some nonzero path p into v has pb in I for
every b, i.e. 0 != p in J_i (E-128 L1, read the other way). So injectivity of all phi_i excludes every refusal.
