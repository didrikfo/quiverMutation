# Round 076 (conference): Maverick

Level: idea. Nothing was run; this is a position statement.

**Most promising question (next few rounds):** Can the Cartan-congruence test (an M-equivariant isometry of G) ever return NO on a pair known to be inequivalent, at n >= 9? Why it matters: it is the one question that decides whether Candidate C (T3/T8) and the NO-power half of the J = 0 join test (T10) are testable at all. Today every Cartan-level YES proves nothing, and the only NO-type results are artificial ((G,M) vs (G,-M)). If the answer is "no, Cartan congruence is blind on this family", both threads should stop at Cartan level and move to a non-Cartan invariant; if "yes", we get the first real power control.

**Outside the thread (dormant):** T6 / H-017, the Euler signature as a lattice invariant. Parked since round 069 on the grounds that it is Cartan-determined. The reframing I would test: a quipu or cord defect as a rank/discriminant datum of the Euler form, compared with the 16 unplaced n = 11 LNAs, which sit in none of the four periodic groups. Nobody has asked whether the unplaced 16 are separated by this lattice rather than by the derived class.

**Weakest claim the workshop relies on:** "25 of 25 failing n = 7 children are in the derived class" (T10). It rests on the J = 0 premise. End(T) cannot see J (E-181, E-191), Hom(T,T[-1]) is nonzero on every J != 0 step, and no join test has returned NO across a J != 0 step with an independent inequivalence certificate. The "subset of 70" and the cyclic-D(i) counterexample (E-211) weaken it further. The Cartan-level analogue for T3/T8 is equally weak: the isometry test is YES-only so far.

**What I need:**

- theorist (or scholar): confirm stage 2 of E-215, the rank-6 indefinite piece of the n = 11 15-group as a rank-1 hermitian lattice over Z[zeta_7] (class number 1). Without it Candidate C stays at idea level.
- skeptic: a hand check that the n = 10 isometry (E-215, P for 90000000 ~ 00000030) is correct on one edge, so the YES control is not itself a bug.
- experimentalist: no new run requested; the S-1 table does not bear on the NO question.
