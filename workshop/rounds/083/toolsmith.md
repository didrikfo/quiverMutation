Every one of the 10 fails `tiltingPlus` and has Hom(T,T[-1]) != 0 (totals 2, 2, 2, 2, 3, 3, 4, 4, 3, 3), so each is a real J != 0 step at the S = -1 placement; no J = 0 explanation. Every child joins 3060000 by J = 0 moves (total 7 or 8, Hom-verified pieces, isomorphic meet). So at this cap, key-kept J != 0 steps occur (about 1 in 500 parents) but none leaves the J = 0 class of 3060000. Not claimed: any statement about 3304000, deeper parents, or a rate beyond depth 5; the joins are a consistency check (the Hom+Cartan part has no NO power, E-228), the iso meet is the check. A key-kept step whose child fails to join would refute "none leaves".
