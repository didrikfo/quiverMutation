# Hereditary triangulated categories

**arXiv:** [1606.08279](https://arxiv.org/abs/1606.08279) · X.-W. Chen,
C. M. Ringel · J. Noncommut. Geom. 12 (2018), 1425–1444 ·
*read 2026-09-19 from the arXiv PDF*

The source of the path criterion that arXiv:2310.08346 uses in
`lemma:taupathimpliesnotpwh`. Read it for **Corollary 5.4**, which is stronger than
the use we make of it: it is a **two-way** characterisation of piecewise heredity,
so it is the only tool in this sweep that can certify an LNA **is** piecewise
hereditary rather than only that it is not.

## The definition everything turns on

In a triangulated category `D` where every object is a finite direct sum of
indecomposables, a **path of length `n`** from `X₀` to `X_n` is a sequence
`X₀, X₁, …, X_n` of **indecomposable** objects such that for each `1 ≤ i ≤ n`,

    Hom_D(X_{i−1}, X_i) ≠ 0   **or**   X_i = X_{i−1}[1].

Note carefully: the Hom need only be nonzero (not non-invertible), the shift step
is *equality*, not "there is a map", and the intermediate objects must be
indecomposable. A path of length 0 exists from any `X` to itself.

(Separately, §5 defines a path to be **proper** when each step is a nonzero
*non-invertible* map or a shift, and `X` **directing** when no proper path of
length ≥ 1 starts and ends at `X`. That notion is used only in Proposition 5.3.)

## Results we use

### Corollary 5.4 — piecewise heredity, both directions

> Let `A` be a finite dimensional **connected** `k`-algebra. The following are
> equivalent:
> 1. `A` is piecewise hereditary;
> 2. for **any** indecomposable `X` in `D^b(A-mod)` there is no path from `X[1]`
>    to `X`;
> 3. there **exists** an indecomposable `X` in `D^b(A-mod)` with no path from
>    `X[1]` to `X`.

The `(1) ⟹ (2)` direction, used contrapositively, is what we already have: exhibit
one path `X[1] ⇝ X` and the algebra is certified not piecewise hereditary. That is
arXiv:2310.08346's `lemma:taupathimpliesnotpwh`, whose examples build the path out
of Auslander–Reiten translates, as `τ^k(P_i) = P_i[j]`.

**`(3) ⟹ (1)` is the half we are not using, and it is the valuable one.** It says
a *single witness* suffices: find one indecomposable `X` with no path from `X[1]`
back to `X`, and the algebra is piecewise hereditary — with no tilting complex, no
weighted projective line, no classification. The authors flag this themselves:

> **Remark 5.2(1).** "the existence of a single indecomposable object with a
> special property forces all the indecomposable objects to have this property!
> This indicates a rather unusual character of homogeneity."

### Theorem 5.1 — the statement behind it

The same trichotomy for a triangulated category `D` which is a **block**
(indecomposable as a triangulated category, equivalently `Ind D` is path-connected,
Proposition 4.2): `D` is hereditary ⟺ no indecomposable `X` has a path `X[1] ⇝ X`
⟺ some indecomposable `X` has none. Corollary 5.4 is this plus Theorem 3.3, which
upgrades the equivalence to a *triangle* equivalence when `D` is algebraic —
`D^b(A-mod)` always is.

### Theorem 2.3 — the `t`-structure version

`D` is hereditary ⟺ `D` has a **hereditary `t`-structure**, i.e. a full additive
`A ⊆ D` with `D = add(⋃_n A[n])`, `Hom_D(A, A[m]) = 0` for `m < 0`, and every
nonzero map out of `A` landing in `A ∪ A[1]`. The proof of `(3) ⟹ (1)` in
Theorem 5.1 constructs exactly such an `A` from the witness `X`, as
`add(U ∩ V[1])` with `U = [X →]` the objects reachable from `X` and `V` the
complement of `V` — worth reading if we ever want the hereditary category itself
and not just its existence.

### Proposition 4.2 — connectedness, and why "block" is not a real hypothesis

> `D` is a block ⟺ the only nonempty path-closed subclass of `Ind D` is `Ind D`
> itself ⟺ `Ind D` is path-connected.

For `A` connected finite dimensional, `D^b(A-mod)` is a block, so Corollary 5.4
drops the hypothesis. Every LNA is connected.

## Lemmas worth knowing

- **Lemma 4.1.** A path-closed subclass of `Ind D` splits `D` as a product of two
  triangulated subcategories. This is the mechanism by which "no path from `X[1]`
  to `X`" propagates from one object to all: the objects with the property form a
  path-closed class.
- **Proposition 5.3.** `D` algebraic and a block has a **directing** object ⟺
  `D ≃ D^b(H)` for `H` hereditary abelian with a directing object. Directing is a
  much stronger and much more checkable condition than the Corollary 5.4 witness;
  if an LNA has a directing indecomposable it is piecewise hereditary, and of a
  restricted kind.
- **Remark 5.2(2).** If a block `D` does *not* have split idempotents, then there
  are paths `X[1] ⇝ X` for every idempotent object. Not relevant to us —
  `D^b(A-mod)` has split idempotents — but it explains why the paper is careful.

## Caveats and limitations

- **The criterion is stated over `D^b(A-mod)`, not over the quiver.** There is no
  combinatorial version. To use `(3) ⟹ (1)` we would need (a) a concrete
  indecomposable `X` and (b) a way to decide "no path from `X[1]` to `X`", which
  means deciding `Hom_{D^b}(Y, Z) = 0` over all indecomposables reachable from
  `X[1]`. For a representation-finite algebra like an LNA the indecomposables of
  `D^b` are the shifts of the indecomposable modules, so `Ind D^b` is finite up to
  shift — but the *path* quantifies over all shifts, so the search is over a
  `Z`-indexed set and needs an argument to terminate. **This is the work that
  stands between us and the criterion.**
- **`(1) ⟹ (2)` gives no recipe for finding a path.** arXiv:2310.08346's
  `lemma:taupathimpliesnotpwh` supplies one — iterate `τ` on a projective and look
  for `τ^k(P_i) = P_i[j]` — and that is the route with a chance of being
  implementable. Chen–Ringel do not provide it.
- **No field hypothesis, which is a genuine advantage**: Corollary 5.4 needs only
  `A` finite dimensional connected over a field `k`. Happel's trichotomy (the
  "`H` is modules or sheaves" refinement) is what needs `k` algebraically closed,
  and Corollary 5.4 does not use it.
- The result identifies "piecewise hereditary". It does **not** distinguish module
  type from sheaf type, which is the distinction that matters for "is this a quipu
  class?" — see the Happel–Seidel file on that trap.

## What it does not give us

- No invariant, no derived equivalence, no merge. It is a membership test for one
  class, in a form we cannot yet run.
- Nothing specific to Nakayama algebras, nor to monomial algebras.

## How it lands on our problem

The asymmetry in our toolkit is that every piecewise-heredity criterion we have is
**negative**: `failsFlankedPairCriterion`, `failsBigOverlapCriterion`,
`notPiecewiseHereditaryByDeletion` all certify "no". Corollary 5.4(3) is the only
statement in this sweep that could certify "yes" for an LNA our quipu inversion
does not name. If someone implements `τ` on `D^b` of an LNA — which
arXiv:2310.08346's note already flags as "the natural next certificate" for the
negative direction — then the *same* machinery gives the positive direction, from
the same paper the negative one is quoted from.
