Two things for us, both unusual in this literature in being *about* `kA_n/I`:

1. **Corollary 3.6** — a purely combinatorial test, on paths in the quiver, for
   whether an HRS-tilt at a (co)hereditary torsion pair gives a derived
   equivalence. Specialised to an LNA it becomes a one-line condition on the
   digit string, and each `S` that passes is a **construction** of an algebra
   derived equivalent to our LNA.
2. **Proposition 3.18 + Corollary 3.20** — every `kA_n/I` is *2-tilting acyclic*,
   and for such algebras the set of torsion pairs inducing derived equivalence is
   a union of maximal chains. In silting language: **irreducible silting mutation
   acts transitively on the two-term tilting complexes over an LNA.** That is a
   reachability theorem for exactly the moves our search makes.

The paper cites arXiv:2310.08346 as [17] and Happel–Seidel as [20] (Example 3.17),
so it already knows our setting.

## Background, in the form we need it

An abelian `A` with a torsion pair `τ = (T, F)`; HRS-tilting gives an abelian
`A_τ ⊆ D^b(A)` and a realisation functor `D^b(A_τ) → D^b(A)`. `τ` **induces derived
equivalence** if that functor is an equivalence; `tors^d A ⊆ tors A` is the class
of such `τ`. `τ` is **hereditary** if `T` is closed under subobjects, **cohereditary**
if `F` is closed under quotients.

> **Theorem 1.4** (Chen–Han–Zhou [14, Thm. A]). `τ = (T, F)` induces derived
> equivalence **iff** for every `a ∈ A` there is an exact sequence
> `0 → f₀ → f₁ → a → t₀ → t₁ → 0` with `t_i ∈ T`, `f_i ∈ F`, representing the zero
> element of `A³(t₁, f₀)`.

Everything in the paper is an application of this.

For `Λ = kQ/I` artin and `S ⊆ Q₀` a set of vertices, `S` also denotes the
corresponding simples and `S^c` the complement. `filt S` is the class of modules
filtered by simples in `S`; it is a TTF-class, giving two torsion pairs
`(⊥S, filt S)` (cohereditary) and `(filt S, S^⊥)` (hereditary).

Two maps on subsets of `Q₀`, both union-preserving:

    Φ⁺({i}) = { j : some path i ⇝ j is **tail-maximal** for I }   (= supp soc P_i)
    Φ⁻({i}) = { j : some path j ⇝ i is **head-maximal** for I }

"Tail-maximal" = cannot be extended at its end without landing in `I`.

## Results we use

### Proposition 3.5 / Corollary 3.6 — the criterion

> **Proposition 3.5.** In `mod Λ`:
> 1. `(⊥S, filt S)` induces derived equivalence **iff** `Φ⁻(S^c) ⊆ S^c`;
> 2. `(filt S, S^⊥)` induces derived equivalence **iff** `Φ⁺(S^c) ⊆ S^c`.

> **Corollary 3.6** (`Λ = kQ/I`). 
> 1. `(⊥S, filt S)` induces derived equivalence iff every nonzero path ending
>    outside `S` prolongs to a nonzero path starting outside `S`:
>    `∀ p : i ⇝ j` with `j ∈ S^c` and `p ∉ I`, `∃ q : j' ⇝ i` with `j' ∈ S^c` and
>    `qp ∉ I`;
> 2. `(filt S, S^⊥)` induces derived equivalence iff every nonzero path starting
>    outside `S` prolongs to a nonzero path ending outside `S`:
>    `∀ p : j ⇝ i` with `j ∈ S^c` and `p ∉ I`, `∃ q : i ⇝ j'` with `j' ∈ S^c` and
>    `pq ∉ I`.

**Specialised to an LNA.** In `kA_n / I` every `soc P_i` is one-dimensional, so
`Φ⁺` and `Φ⁻` are single-valued. Write, for the digit string `d` (`d[s]` = number
of arrows of the relation starting at `s`, `0` if none):

    m(i) = min( n, min{ s + d[s] − 1 : s ≥ i, d[s] ≠ 0 } )   — end of the longest nonzero path from i
    w(i) = max( 1, max{ s + 1      : s + d[s] ≤ i, d[s] ≠ 0 } ) — start of the longest nonzero path into i

Then the criterion collapses to:

| torsion pair | induces derived equivalence iff |
|---|---|
| `(filt S, S^⊥)` | `S^c` is closed under `m`: `i ∉ S ⟹ m(i) ∉ S` |
| `(⊥S, filt S)` | `S^c` is closed under `w`: `i ∉ S ⟹ w(i) ∉ S` |

Checked against the paper's own **Example 3.9**: for `Λ = kA_n/rad²`, `m(i) = i+1`,
so `S^c` closed under `m` means `S` is an initial segment `{1,…,k}`, giving exactly
`n + 1` hereditary torsion pairs that induce derived equivalence — which is what
the paper states.

**Why this is a merge tool.** For a finite dimensional algebra every `filt S`
torsion pair is functorially finite, so the HRS tilt `A_τ` is `mod Γ` for an
algebra `Γ` — and when the criterion passes, `D^b(Γ) ≃ D^b(Λ)`. So each admissible
`S` *builds* an algebra derived equivalent to our LNA. `Γ` is the endomorphism
algebra of the corresponding two-term tilting complex; for `|S| = 1` this is a
single tilting mutation. For `|S| ≥ 2` it is a simultaneous mutation at several
vertices, which our engine does not do in one step.

### `|S| = 1` reproduces `procedure.isMutable` — exactly, on everything tested

Worked out by hand and then checked. With `S = {v}` the `Φ⁺` condition says: no
`i ≠ v` has `m(i) = v`. Unpacking, `m(i) = v` for some `i ≠ v` happens **iff**
`v = n` (the arrow `n−1 → n` is never in `I`, so `m(n−1) = n`) or some relation
**ends at `v+1`** (take `i` = that relation's start; minimality of the relations
forbids any shorter nonzero path from `i` stopping earlier). So

> `(filt S_v, S_v^⊥)` induces derived equivalence ⟺ `v ≠ n` and **no relation ends
> at `v + 1`**.

which is verbatim the two impossibility cases arXiv:2112.08129 gives for the
linear quiver: no arrow out of `v`, or a nonzero path ending at `v` whose
composite with the one arrow out of `v` is zero.

**Checked 2026-09-19** against `procedure.isMutable` over every LNA and every
vertex at `n = 4 … 9` — `5 + 14 + 42 + 132 + 429 + 1430 = 2052` algebras: **zero
disagreements**. (The `Φ⁻` / cohereditary version disagrees everywhere, as it
must — it is the opposite-convention, left-mutation statement.)

### Proposition 3.18 — every `kA_n/I` is 2-tilting acyclic

`Λ` is **acyclic** if there is no cyclic chain of nonzero non-invertible maps
`P₁ → P₂ → ⋯ → P_n → P₁` between indecomposable projectives. `Λ` is **2-tilting
acyclic** if `End(T)` is acyclic for every two-term tilting complex `T`.

> **Proposition 3.18.** For `Λ = kA_n/I` there are no cyclic chains of nonzero,
> non-invertible morphisms between indecomposable objects of
> `K := K^{[−1,0]}(proj Λ)`. In particular `Λ` is 2-tilting acyclic.

The proof is elementary and specific to the line: the linear order on `A_n` gives
`Hom(P_i, P_j) = 0` for `i < j` and, for `i ≥ j ≥ k` with `Hom(P_i, P_k) ≠ 0`, any
two nonzero maps `P_i → P_j → P_k` compose to a nonzero map. The indecomposables of
`K` are stalk complexes and two-term complexes `(P_i → P_j)` with `i ≥ j`; a cycle
is sectioned into paths between two-term complexes, and each such path is shown to
weakly decrease both `i` and `j` with at least one strict decrease.

**Note the convention**: Pavon's `A_n` is `1 → 2 → ⋯ → n` but his projectives
satisfy `Hom(P_i, P_j) ≠ 0` iff the path `j ⇝ i` avoids `I`, i.e. the opposite of
the repo's reading. Since the relation dual (arrow reversal) is a derived
equivalence we already use, this only matters when transcribing which of `m` or
`w` goes with which torsion pair — derive it rather than copy it.

Also recorded in **Example 3.16**: *piecewise hereditary ⟹ acyclic* (Happel's
book, Lemma IV.1.10) *⟹ 2-tilting acyclic*. So the property is automatic for every
LNA in a quipu class; Proposition 3.18 is what extends it to the LNAs that are not
piecewise hereditary, which is the interesting case.

### Lemma 3.14 + Proposition 3.19 + Corollary 3.20 — the reachability statement

> **Lemma 3.14.** If `Λ` is acyclic, then for every `(T, F) ∈ tors^d Λ` there are
> simples `S_t ∈ T`, `S_f ∈ F` with
> `(filt S_t, S_t^⊥) ≤ (T,F) ≤ (⊥S_f, filt S_f)`, both endpoints in `tors^d Λ`.

> **Proposition 3.19.** Let `Λ` be 2-tilting acyclic and `σ, τ ∈ tors^d Λ` with `σ`
> functorially finite. If `σ ≤ τ` there is functorially finite `σ' ∈ tors^d Λ` with
> `σ ⋖ σ' ≤ τ`; dually if `τ ≤ σ`.

> **Corollary 3.20.** Let `Λ` be 2-tilting acyclic. If `f-tors^d Λ` is finite then
> `f-tors^d Λ = tors^d Λ`, and `tors^d Λ` is a **union of maximal chains** in
> `tors Λ`.

The hypothesis holds for every LNA: a Nakayama algebra is representation-finite,
hence `τ`-tilting finite, hence `tors Λ` — and so `f-tors^d Λ` — is finite.
*(r055: this chain is our inference. The paper proves Prop 3.18 for `kA_n/I` and
mentions representation-finite piecewise hereditary algebras and `τ`-tilting
finite symmetric algebras as examples in Question 3.21; it cites Demonet–Iyama–
Jasso [Thm 3.12 in the source] for "`τ`-tilting finite iff `tors` finite", and
never says "Nakayama algebra, hence finite" in one line.)*

The paper's own translation (§3.2 opening): `tors^d(Λ)` being a union of maximal
chains in `tors(Λ)` is the same as **irreducible silting mutation acting
transitively on two-term tilting complexes**. So, for an LNA:

> Starting from `Λ` itself, every two-term tilting complex over `Λ` can be reached
> by a sequence of single irreducible mutations, **each intermediate step of which
> is again a tilting (not merely silting) complex**.

No dead ends, and no need to pass through a step that fails to be a derived
equivalence.

## Caveats and limitations

- **"Two-term" is the whole restriction, and it is severe.** The statement is about
  `K^{[−1,0]}(proj Λ)` — complexes concentrated in degrees `−1, 0`. The derived
  class of `Λ` contains algebras realised only by tilting complexes of larger
  width, and Corollary 3.20 says nothing about reaching those. Our search reaches
  them by *iterating* — each step is two-term over the current algebra, not over
  `Λ` — and the theorem does not compose along such a chain, because "2-tilting
  acyclic" is checked for `Λ` and the endomorphism algebra of a two-term tilting
  complex over an LNA need not be an LNA. **This is not a proof that our search is
  complete.** It is the statement that no single stage of it has dead ends.
- `tors Λ`, `tors^d Λ` and the counts in Example 3.8 are invariants of the
  **algebra**, not of its derived class. Nothing here separates two LNAs.
- Corollary 3.6 characterises when a **(co)hereditary** torsion pair works. Most
  torsion pairs are neither, and the criterion says nothing about them.
- The realisation functor and `A_τ` are only guaranteed to be `mod Γ` when `τ` is
  functorially finite. For `filt S` with `S` a finite set of simples over a finite
  dimensional algebra this is automatic, but the general statements in §2 are not
  about module categories.
- **Question 3.21 is open**: there is no characterisation of the algebras for which
  `tors^d(Λ)` is a union of maximal chains; 2-tilting acyclicity is sufficient, not
  necessary (his `Λ_n = kQ/rad^n` on the two-cycle, `n` odd, is neither acyclic nor
  a counterexample).
- Example 3.17 notes, correctly and in passing, that "for small values of `n`, all
  algebras of the form `kA_n/I` are piecewise-hereditary" and cites
  arXiv:2310.08346 for the counterexamples — but 2-tilting acyclicity is proved
  outright in Proposition 3.18, so it does **not** depend on piecewise heredity.

## What it does not give us

- No invariant, and no separation of two LNAs.
- No explicit description of the algebra `Γ` on the other side of an admissible
  HRS-tilt; only that it exists and is derived equivalent.
- Nothing about tilting complexes of width `> 2`, which is where the interesting
  part of an LNA's derived class lives.

## How it lands on our problem

Two jobs, in order of value:

1. **R-005's gap, possibly closed.** Corollary 3.6 with `|S| = 1` gives, for
   `kA_n/I`, an **iff** condition for an HRS-tilt at a single simple to be a
   derived equivalence, and that condition agrees with `procedure.isMutable` on
   every LNA at `n ≤ 9`. arXiv:2112.08129 could only prove the condition
   necessary. Establishing that the repo's mutation at `P_v` *is* the HRS-tilt at
   `(filt S_v, S_v^⊥)` would upgrade the gate from necessary to exact for LNAs —
   the single most valuable follow-up in this file.
2. **A partial answer on search completeness.** The repo's open worry is whether
   mutation search can reach everything in a derived class. Corollary 3.20 says: at
   each stage, the two-term part of the search space is connected, and every
   two-term tilting complex is reachable by single irreducible mutations that never
   leave the tilting locus. It does **not** close the question — see the caveat —
   but it removes the failure mode where a class is unreachable because every route
   to it passes through a non-tilting silting complex.

Also worth recording: `|S| ≥ 2` in Corollary 3.6 is a **simultaneous mutation at a
set of vertices**, a move our engine does not have. If the digit-string rules turn
out to be blocked (F-023), a set-mutation with a clean combinatorial admissibility
condition is an obvious thing to try next.
