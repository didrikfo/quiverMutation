# Quipu quivers and Nakayama algebras with almost separate relations

**arXiv:** [2305.06642](https://arxiv.org/abs/2305.06642) · D. Fosse

Classifies linear Nakayama algebras with almost separate relations up to derived
equivalence, by identifying each class with a quipu.

## Definitions to keep straight

`A_{n,(n_0,…,n_r)}^{(l_0,…,l_r)}` is `kA_n / I` with a relation of `l_i` **arrows**
starting at vertex `n_i`. Assumptions: `n_i < n_{i+1}`, `n_i + l_i < n_{i+1} + l_{i+1}`,
`n_r + l_r ≤ n`. Length always means **number of arrows**, so the shortest
admissible relation has length 2.

**Almost separate relations**: consecutive relations overlap in at most one arrow,
`n_{i+1} ≥ n_i + l_i - 1`. This is the restriction the whole paper works under.

An **open quipu** is a tree of maximum degree 3 whose degree-3 vertices all lie on
one path (the *main string*); the other branches are *cords*. Written
`P^(m_0,…,m_r)_(k_0,…,k_{r+1})`: `m_i` is the length of cord `i`, `k_i` the number
of main-string vertices between consecutive cord feet. Vertex count is
`r + 1 + Σk + Σm`.

**The notation is not unique** — reading the main string from the other end, or
swapping an end segment with the cord at the outermost foot, gives another valid
parameter pair for the same graph. `quipuForms.quipuParameters` canonicalises by
taking the lexicographically smallest pair over every valid reading.

## The main theorem (`thm:QuipuToAn`)

With `n_i = k_0 + Σ_{j=1..i} (m_{j-1} + k_j + 1)`, the path algebra of a quipu
quiver `D` satisfies

    kD ≃ A_{n_{r+1}, (k_0, n_1, …, n_r)}^{(m_0+2, …, m_r+2)}

**if and only if** `D` is that quipu with some orientation.

The "only if" is what makes it a *complete* invariant: an LNA with almost separate
relations is derived equivalent to one quipu shape and no other. That is what lets
two classes sharing a Coxeter polynomial be told apart (F-010).

**Inverted** in `quipuForms.quipuForAlmostSeparateLNA` — see F-003 — which names a
class in O(1) with no searching.

## The class-preserving operations (`cor:EquivNakayamaAlgebras`)

Within a class, all LNAs with almost separate relations are related by:

1. changing the length and end vertex of the **first** relation, or the start
   vertex of the **last**, by a certain amount;
2. adding or removing relations of **length 2**;
3. reversing all arrows (the relation dual).

There are at most 8 such algebras per class with all relations of length ≥ 3.

Operation 3 is why searching from the relation dual covers the other direction of
a one-way reachability (F-007). Operation 2 is why the theorem's inverse drops
length-2 relations first.

## The n ≤ 8 table

Every class for n ≤ 8, as a quipu with its corresponding Nakayama algebras.
Transcribed in `tests/paper_classification.py` and used throughout the tests.
Quipu counts by order: 1, 1, 1, 2, 2, 4, 6, 11 for orders 1–8; `allQuipusOfOrder`
reproduces these and continues 18, 36, 64, 127.

## Caveats and limitations

- **It covers only almost separate relations.** LNAs with bigger overlap are
  outside it entirely. That is where the classes that are *not* quipu classes
  live (F-011), and where the rows a search still has to place are (H-003).
- A class generally contains further LNAs beyond those the paper lists — ones with
  bigger overlap — which the table does not enumerate.
- The paper notes explicitly that the Coxeter polynomial is **not** a complete
  invariant. F-010 makes that precise: it fails exactly at cospectral quipus, of
  which there are none below order 9.
- **What "derived equivalent to a quipu" does not cover**: a tree of maximum
  degree 4, or with degree-3 vertices off the main string, is not a quipu. Whether
  such a tree algebra can be derived equivalent to an LNA is open here (H-006).
