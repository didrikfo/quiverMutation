# Derived-tame tree algebras

**Th. Brüstle**, *Derived-tame tree algebras*, Compositio Math. **129** (2001)
301–323. DOI `10.1023/A:1012591326777`.
**Not on arXiv.** Read 2026-09-19 from the Cambridge Core PDF, all 23 pages.
Ch. Geiß obtained the same two theorems independently by different methods
(*Derived tame algebras and Euler forms*, Math. Z. **239** (2002) 829–862); the
paper says so on p. 4.

Found by chasing the citation in arXiv:1910.01494 §3.3, which disposes of the
line-algebra case of its own main theorem by pointing here. **This is the more
valuable of the two papers by a wide margin**, because it does not merely split
tame from wild — it **classifies the derived-tame tree algebras up to derived
equivalence, completely, by three computable numbers.**

Every LNA is a tree algebra: `A = kQ/I` basic and connected with `Q` a tree
(`A_n` linearly oriented is a tree) and `I` admissible (generated by paths, so
by zero-relations). **No further hypothesis.** So both theorems below apply
verbatim to every `kA_n/I` we consider, at every `n`, with relations of any
lengths.

## The two theorems

Write `h_A(x) = x^T(C_A^{-1} + C_A^{-T})x` for the homological quadratic form, in
our usual convention (the same one as the 1310.1557 file); `χ_A = h_A/2` is
Brüstle's Euler form, a unit form (`χ_A(e_i) = 1`). "Non-negative" means
**positive semidefinite on all of `Z^n`** — *not* "weakly non-negative", not just
on the positive cone. I checked the distinction matters: the two `n = 10`
outliers below are positive semidefinite-failing but, as far as a search over
small non-negative integer vectors goes, weakly non-negative.

> ### Theorem 1.1
> **A tree algebra is derived-tame precisely when its Euler form is
> non-negative.**

> ### Theorem 1.2
> Let `A` be a **connected derived-tame tree algebra**. Then `A` is derived
> equivalent to a hereditary algebra of type `E_p` or `Ẽ_p`, or to a tubular
> algebra, or to **precisely one** of the algebras `S(n,m)`. In particular, `A`
> is, up to derived equivalence, **determined by the number of vertices, the
> corank and the Dynkin type of its Euler form.**

Brüstle's "derived-tame" is *the repetitive category `Â` is tame*. For `A` of
finite global dimension `D^b(A) ≃ mod Â`, and every LNA is triangular so
`gl.dim < ∞`. (arXiv:1910.01494 uses the Bekkert–Drozd parametrising-set
definition instead and treats the two as interchangeable; **I did not verify
that equivalence**, but nothing below depends on which one is meant, since
Theorem 1.2's invariant is stated in terms of the Euler form alone.)

### Table I — which types occur, by corank

| corank `m` | type `A_n` | type `D_n` | type `E_p` |
|---|---|---|---|
| `0` | `kA_n` | `kD_n` | `kE_p` |
| `1` | — | `kD̃_n` | `kẼ_p` |
| `2` | — | `S(n-1,3)` | **tubular** |
| `≥ 3` | — | `S(n-1,m+1)` | — |

"—" means *no tree algebra exists* with that corank and type. So **type `A` only
at corank 0**, and **type `E` only up to corank 2**; everything of corank ≥ 3 is
of type `D` and is a semichain. (The `n` in the table is the Dynkin index, not
the vertex count; see the bookkeeping below.)

Corollary 1.3 adds: a derived-tame tree algebra contains a subcategory derived
equivalent to `E_6` precisely when it contains a convex subcategory derived
equivalent to hereditary `E_p`/`Ẽ_p` (`p = 6,7,8`) or to a tubular algebra —
the practical way to tell Dynkin type `D_n` from `E_p` by hand, using the list
in [7].

### The semichain `S(n,m)`

Defined in §2.5, Example (1): take the hereditary chain
`d_1 → d_2 → ⋯ → d_m → s_{m+1} → ⋯ → s_n` (`kA_n`, no relations) and **blow up**
each of `d_1,…,d_m` into a pair `d_i^+, d_i^-`, replacing every arrow into (resp.
out of) `d_i` by one arrow into (resp. out of) each of `d_i^±`, and imposing the
**commutativity relations** `b^+a^+ = b^-a^-` at every resulting square. Then

- `S(n,m)` has **`n + m` vertices**;
- `S(n,0) = kA_n`; `S(n,1) = kD_{n+1}` (two sources feeding one chain — no
  squares, so hereditary); `S(2,2)` is the `K_{2,2}` quiver, tame hereditary of
  type `Ã_3`; `S(n,2)` is derived equivalent to tame hereditary `D̃_{n+1}`;
- in general, for `n > m ≥ 1`, `S(n,m)` has **non-negative Euler form of corank
  `m-1` and Dynkin type `D_{n+1}`**.

**`S(n,m)` is not itself a tree algebra** (that is why Brüstle has to build the
induction inside the wider class of *semi-tree algebras* `A[D]`, §2.6). It is the
target of the classification, not a member of the classified family.

### Bookkeeping: the representative of an LNA's class

For an LNA on `N` vertices with non-negative Euler form of corank `m` and Dynkin
type `X_r`, necessarily `r = N - m`, and the representative is:

| corank | type | representative | check |
|---|---|---|---|
| `0` | `A_N` | `kA_N` = `S(N,0)` | `N` vertices |
| `0` | `D_N` | `kD_N` = `S(N-1,1)` | `N` vertices |
| `0` | `E_N`, `N ∈ {6,7,8}` | `kE_N` | |
| `1` | `D_{N-1}` | `kD̃_{N-1}` ≃ `S(N-2,2)` | `D̃_r` has `r+1` vertices |
| `1` | `E_{N-1}`, `N ∈ {7,8,9}` | `kẼ_{N-1}` | |
| `2` | `D_{N-2}` | `S(N-3,3)` | `(N-3)+3 = N` |
| `2` | `E_{N-2}`, `N ∈ {9,10}` | tubular | `(2,4,4)` at 9, `(2,3,6)` at 10 |
| `m ≥ 3` | `D_{N-m}` | `S(N-m-1, m+1)` | `(N-m-1)+(m+1) = N` |

Uniformly for type `D`: **corank `m` ⟹ `S(N-m-1, m+1)`**.

## How to compute the invariant

`C_A` is the Cartan matrix, `(C_A)_{ij} = 1` iff the path `i → j` survives in
`kA_n/I` (i.e. `i ≤ j` and no relation `(s,l)` has `i ≤ s` and `s+l ≤ j`), else 0
— unitriangular, so `C_A^{-1}` is integral. Put `G = C_A^{-1} + C_A^{-T}`, an
integer symmetric matrix with diagonal `2`, so `h_A(x) = x^T G x` and
`χ_A(x) = ½ x^T G x`. Then

1. **derived tame** ⟺ `G` positive semidefinite (least eigenvalue ≥ 0);
2. **corank** `m = n − rank G`;
3. **Dynkin type**: the radical of `χ_A` is a saturated sublattice, so the
   induced positive definite form on `Z^n/rad` has Gram determinant equal to the
   **product of the nonzero elementary divisors of `G`** (Smith normal form).
   With `r = rank G`, read the type off `(r, det)` against the Cartan
   determinants: `A_r → r+1`, `D_r → 4` (`r ≥ 4`), `E_6 → 3`, `E_7 → 2`,
   `E_8 → 1`. Unambiguous (the only clash, `A_3 = D_3`, is the true coincidence).

Cheap: one matrix inverse and one Smith normal form per LNA.

## What this gives us — the merging criterion we were missing

**For every LNA with non-negative Euler form, the derived equivalence class is
completely determined, with no search, by `(n, corank, Dynkin type)`.** Two such
LNAs agreeing on all three **are** derived equivalent; disagreeing on any one,
they are **not**. This is a two-sided criterion, unlike everything else we have,
and it is not restricted to the almost-separate case — it does not look at the
relations at all, only at the Cartan matrix.

### Piecewise heredity, read off the same two numbers

Within the derived tame range this is a complete answer:

> **corank 0** → Dynkin hereditary; **corank 1** → Euclidean hereditary;
> **corank 2, type `E`** → tubular, i.e. canonical type;
> **corank ≥ 2, type `D`** → a semichain, and **not piecewise hereditary**.

The last line because: a piecewise hereditary algebra is of hereditary type or of
canonical type (Happel); a hereditary algebra with non-negative Euler form is
Dynkin or Euclidean, corank ≤ 1; a canonical algebra with non-negative form of
corank 2 is tubular; and Theorem 1.2's "precisely one" separates the type-`D` box
from the tubular box. This is exactly the H-006 trichotomy — **plus the fourth
box the trichotomy is missing, the semichains.**

Cross-checked against the code: the corank-≥2 type-`D` LNAs at `n = 9,10,12` are
`3033030`; `33033030, 30233030, 30330230, 30330330, 30330030, 30033030`;
`3033033030` (corank 3, `S(9,4)`) — and `piecewiseHereditary`'s existing
`notPiecewiseHereditaryByDeletion` **already certifies every one of them**, all
via Proposition A9 (directly, or after one vertex deletion, for the two that need
it). So this is a second, independent proof of what we already certify, not new
coverage. The converse is also worth recording: `34504030` and `50505000` are
derived **wild**, so Brüstle says nothing about them — which is why they still
needed `lemma:taupathimpliesnotpwh`.

### Answering H-006 in the derived tame range

Every representative in Theorem 1.2 that is a *hereditary tree* is of type
`A_n, D_n, E_{6,7,8}, D̃_n, Ẽ_{6,7,8}` — and **every one of those is an open
quipu** (a single degree-3 vertex, or for `D̃_n` two degree-3 vertices on one
path). So: **no derived-tame LNA is derived equivalent to the path algebra of a
tree with a degree-4 vertex, or with degree-3 vertices off the main string.**
H-006 is settled for the derived tame LNAs; the wild ones are untouched.

## Caveats and limitations

- **It says nothing about derived wild LNAs, and they are the majority and
  growing** — at `n = 13`, 200651 of 208012. The wild quipu classes, F-010's
  cospectral pairs among wild quipus, and everything hard in the project live
  outside this theorem. Do not read the table above as a classification of LNAs.
- **"Non-negative" is positive semidefinite, not weakly non-negative.** Getting
  this wrong changes the answer: `34504030` has least eigenvalue `−0.462`, so it
  is derived wild, yet a search over small non-negative integer vectors found no
  `x ≥ 0` with `χ(x) < 0`. Use eigenvalues (or an `LDL^T`), not a positive-cone
  search.
- **Algebraically closed field**, as always. Same caveat as the Happel–Seidel
  file: our criteria that are field-independent are worth more.
- `S(n,m)` **is not a tree algebra**, and it is not an LNA either — so "derived
  equivalent to `S(N-m-1,m+1)`" is a *name* for a class, not a member of it.
  The name is still useful: it is what lets us say `3033030` is alone in its
  class without searching.
- **The "precisely one" in Theorem 1.2 is what makes the criterion two-sided.**
  Dropping it would leave only "these three numbers are derived invariants",
  which is far weaker and is all the 1310.1557 file currently claims.
- Theorem 1.2 is stated for **connected** algebras. Every LNA is connected, so
  this never bites, but a vertex-deletion argument could produce a disconnected
  algebra and the theorem would not apply to it as stated.
- I reconstructed `S(n,m)`'s quiver from §2.5 Example (1) and the blow-up
  definition, not from the figure on p. 2, which does not survive text extraction
  from the PDF. The vertex count, corank and Dynkin type all check out against
  the paper's own remarks (`S(n,0) = kA_n`, `S(n,1) = kD_{n+1}`, `S(2,2) = Ã_3`,
  `S(n,2) ~ D̃_{n+1}`, corank `m-1`, type `D_{n+1}`), so I am confident in the
  shape, but **the figure itself is unverified.**

## This upgrades a caveat already in the directory

The 1310.1557 file records de la Peña's warning that

> `h_A` positive definite (resp. non-negative of corank 1) iff `A` is derived
> equivalent to `k∆` with `∆` Dynkin (resp. extended Dynkin)

**cannot be used in the "if" direction**, because §6.2 of that paper exhibits,
for every `n ≥ 7`, algebras `A_n` and `B_n` with the same positive definite `h`
but `B_n` wild. Correct — **and the counterexamples are not tree algebras**:
`A_n` carries a *commutativity* relation, which needs two parallel paths, so its
quiver has an undirected cycle. **Brüstle's Theorem 1.1 restores the converse for
trees**, hence for every LNA. So for us the safe direction is no longer the only
direction:

- `h_A` positive definite ⟹ the LNA **is** derived equivalent to `kA_n`, `kD_n`
  or `kE_p` (which one: by the Dynkin type, or just by the Coxeter polynomial);
- `h_A` non-negative of corank 1 ⟹ derived equivalent to `kD̃_r` or `kẼ_r`;
- `h_A` non-negative of corank ≥ 2 ⟹ tubular, or a semichain and not piecewise
  hereditary.

The 1310.1557 file's warning should be read as "outside trees"; inside trees the
biconditional holds. **I have not edited that file.**

## The self-check I ran, and it passed

The Coxeter polynomial is a derived invariant, so a Brüstle class must carry
exactly one of them — a cheap falsification test for both the theorem as I have
stated it and my implementation of the invariant. **For every `n` from 4 to 12,
every one of the computed classes has exactly one Coxeter polynomial. Zero
failures.** The converse fails, as expected and as required for this to be worth
anything: at `n = 10` the polynomial `T^10 + T^9 + T + 1` is shared by the
321-member corank-0 `D_10` class and by `34504030` and `50505000`, which are
derived wild and so outside Theorem 1.2's reach — and which F-037 has since shown
are **one class**, joined by seven mutations, not two. Brüstle separates them from
the tame class that shares their polynomial; it does not, and cannot, say anything
about how they stand to each other. At `n = 9`, `3033030` shares its polynomial
with nothing.

Two further consistency checks, both passed: the all-zeros string gives corank 0
type `A_n` at every `n`; and corank 1 always produced type `X_r` with `r + 1 = n`,
as it must if the representative is the Euclidean `X̃_r`.

## What to implement

`euler.corank` and `euler.dynkinType` from the Smith normal form of
`C^{-1} + C^{-T}`, and a classifier that, for any LNA with non-negative form,
returns the class name directly. It would place 7361 of the 208012 LNAs at
`n = 13` into 5 classes, proved, with no mutation search — and it decides both
directions, so it can be used to **merge** as well as to separate. That is the
first tool we have that merges outside the almost-separate case.
